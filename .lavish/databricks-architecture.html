Unity Catalog + DeltaStore ordered story passages, teacher-curated opportunities, sourced Braille similarity rules, and durable session analytics. Cache the small reference set for live use.

NotebookLoad demo data, clearly label synthetic histories and inspect outcomes. No Spark job per dot or learner response.

Lean fallback: if Lakebase is unavailable, keep session state in the local Python runtime, send the latest state on every request, and persist event batches to Delta. Databricks still makes the teaching decisions.

Monday → Tuesday → Wednesday

Apple / A: known letter → continue. Pear / P: weak letter → inspect pear → show P → record incorrect answer. Plum / P: updated state contains the pear error → choose another short P activity.

Wait for the Tuesday answer before finalizing Wednesday’s intervention. Prefetch narration, but recompute the teaching decision using the latest event.

The model chooses a letter; a deterministic local Braille lookup maps it to dots and calibrated servo positions. The original passage text is immutable; generated teaching audio plays between passages.

Keep the MVP focused

Skip vector search for a single short story, multi-agent orchestration, model fine-tuning and extensive dashboards. Confirm the YOLO model actually recognizes pear and plum; otherwise use a tested custom model or explicit teacher confirmation.

On invalid output or network timeout, continue the approved narration without a new hardware action. Keep credentials in the local backend and use event IDs to prevent duplicate scoring.
